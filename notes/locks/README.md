# Spinlock 与读写锁对比

用同一组 pthread 读写任务测试 `spinlock.h` 中的两种锁。

```sh
cc -std=c11 -O2 -Wall -Wextra -Wpedantic -pthread main.c -o spinlock_demo
./spinlock_demo           # 依次运行 spinlock、rwlock
./spinlock_demo spinlock  # 单独运行 spinlock
./spinlock_demo rwlock    # 单独运行 rwlock
./spinlock_demo both 512  # 两种锁都在每次持有读锁期间做 512 轮计算
```

每轮启动 10 个读线程和 2 个写线程，每个线程获取锁 20000 次。所有线程创建后，主线程统一发出开始信号。

- 写线程持锁将计数加 10，再把新值写到镜像计数。两种锁都使用相同的读取、计算、写回操作。
- 读线程持锁读取两个计数，检查同一快照中的两个值是否一致，以及自身连续观察到的计数是否单调不减。
- 第二个参数 `read_work` 控制读临界区中的计算轮数，默认值为 `0`。计算放在两次读取之间，使用线程局部变量，并在结束时输出 checksum。两种锁执行相同的计算，写临界区长度不变。checksum 取决于各线程读到的值。
- 主线程等待所有线程退出，检查两个计数最终是否都等于 400000。计时从发出开始信号前到所有线程 join 完成，单位为毫秒。
- 每轮最多等待 5 秒。超时退出码为 124，该轮无法得到完整耗时。

Spinlock 用同一把独占锁保护读写。读写锁的预期行为是允许多个读者同时进入，并让写者独占。测试对共享字段使用 relaxed 原子访问，以便在待测锁行为异常时仍能执行检查。测试通过仅表示本轮观察到了预期结果。
