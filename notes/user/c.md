# ELF (Executable and Linkable Format)

Includes:
1. Relocatable File(.o File): Generated by compiler and assembler, the address in the file has not been bound, waiting linker to process.
2. Executable File(.exe File): Processed by the linker, the address in the file has been bound, and the program can be executed by OS kernel.
3. Shared Object File(.so File): Dynamic link library, to be used as other programs' dynamic link library.
4. Core Dump File(.core File): The core dump file is a file that contains the memory image of the process at the time of a crash.

```txt

           [ 链接视图 (Linker View) ]                    [ 执行视图 (Execution View) ]
         （用于编译/链接，基于 Sections）              （用于内核加载运行，基于 Segments）
     ┌────────────────────────────────────┐       ┌────────────────────────────────────┐
     │             ELF Header             │       │             ELF Header             │
     ├────────────────────────────────────┤       ├────────────────────────────────────┤
     │       Section Header Table         │       │       Program Header Table         │
     ├────────────────────────────────────┤       ├────────────────────────────────────┤
     │       .text (代码段)               │       │     Segment 1 (只读可执行代码)     │
     │       .rodata (只读数据)           │──────>│     包含 .text、.rodata            │
     ├────────────────────────────────────┤       ├────────────────────────────────────┤
     │       .data (已初始化数据)         │       │     Segment 2 (可读可写数据)       │
     │       .bss (未初始化数据)          │──────>│     包含 .data、.bss             │
     ├────────────────────────────────────┤       ├────────────────────────────────────┤
     │       .symtab (符号表) / 调试信息  │       │                                    │
     └────────────────────────────────────┘       └────────────────────────────────────┘
```
